# Çay Demleme Süresine Göre Hayat Tavsiyesi

## Resmî Beyanname

Bu depo, çayın demlenme süresini **hayatın en yüksek karar organı** ilan eder.

Bilimsel makale değildir. Daha iyisidir: **iddialıdır**.

Türkiye'nin her evinde bir çaydanlık vardır. Bu yazılım o çaydanlığın avukatı, kâtibi ve hafif küstah danışmanıdır.

## Kurulum

```bash
git clone https://github.com/Tentivory/cay-demleme-suresine-gore-hayat-tavsiyesi.git
cd cay-demleme-suresine-gore-hayat-tavsiyesi
python3 tavsiye.py 5
```

Argüman vermezsen yazılım sana sorar. Çünkü çay da sorar.

## Kullanım Örnekleri

| Dem (dk) | Resmî Sınıf | Beklenen Sonuç |
|---:|---|---|
| 1-2 | kisa | Karar alma, çay daha uyanmadı |
| 3-6 | orta | Denge. Konuşma ama bak |
| 7-14 | uzun | Acılaştı, sen acılaşma |
| 15+ | cok_uzun | Bu artık belge, arşive kaldır |

## Metodoloji

1. Kullanıcı bir sayı girer.
2. Yazılım o sayıyı ciddiye alır.
3. Rastgele ama kategorili bir cümle seçilir.
4. Damga basılır.
5. Hayat değişmez. Ama resmiyet artar.

## Gizli Not

Kaynak kodda bir satır vardır. O satırı görmedin. Gördüysen de çaydır.
